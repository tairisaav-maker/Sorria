# Sorria — Guia rápido

**Gestão inteligente para consultórios**

## Primeiros passos

1. Entre com sua conta  
2. Complete o onboarding (clínica, perfil, horários) — pode retomar depois  
3. Cadastre um paciente  
4. Agende uma consulta  

## Módulos

| Módulo | O que faz |
| --- | --- |
| Agenda | Consultas, confirmações, solicitações |
| Pacientes | Cadastro administrativo |
| Prontuário | Anamnese, evolução, odontograma (profissional clínico) |
| Tratamentos | Planos, apresentação, aceitação |
| Financeiro | Parcelas, pagamentos, despesas |
| Relatórios | Indicadores permissionados |
| Secretária Virtual | Assistente administrativa (não clínica) |
| Portal | Paciente solicita/confirma horário |

## Secretária Virtual

Consulta dados administrativos e pode **preparar** ações.  
Ações importantes pedem confirmação.  
Não diagnostica nem decide conduta.
